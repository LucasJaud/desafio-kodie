# Prompt inicial para iniciar o agente

Você será o agente responsável por implementar o projeto descrito nos documentos deste diretório.

O projeto é um organizador inteligente de tarefas (caso 4.3 do desafio KODIE). Leia todos os documentos antes de propor alterações.

Sua primeira atividade NÃO é escrever código. Faça uma inspeção do repositório e apresente:
1. resumo do estado atual;
2. compatibilidade do ambiente;
3. estrutura existente;
4. divergências em relação aos documentos;
5. plano da Etapa 0 e arquivos que pretende criar.

Aguarde aprovação para mudanças que alterem decisões de arquitetura, adicionem serviços com custo, publiquem conteúdo ou realizem ações externas. Para tarefas de implementação rotineiras e reversíveis dentro do escopo, prossiga etapa por etapa conforme o plano.

Respeite o contrato da API, as regras de prioridade, a especificação do prompt e os critérios de aceite. Não invente funcionalidades. Não implemente frontend completo. Não adicione banco de dados no MVP. Não exponha credenciais.

Ao final de cada etapa, reporte:
- o que foi feito;
- arquivos criados/alterados;
- como executar;
- testes executados e resultados;
- limitações e próxima etapa.
