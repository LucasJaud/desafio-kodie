
# Instruções do projeto

Este projeto implementa o desafio técnico KODIE,
com foco na organização inteligente de tarefas.

## Documentação obrigatória

Antes de implementar qualquer funcionalidade, leia
todos os documentos em:

docs/planejamento/

Siga especialmente:
- 00_GUIA_DO_AGENTE.md
- 03_ARQUITETURA_E_DECISOES.md
- 04_CONTRATO_DA_API.md
- 07_PLANO_DE_IMPLEMENTACAO.md
- 08_TESTES_E_CRITERIOS_DE_ACEITE.md

## Regras

- Utilize Python e FastAPI.
- Utilize Pydantic para validação.
- Utilize n8n para automação.
- Não desenvolva frontend completo.
- Não adicione banco de dados ao MVP.
- Não exponha credenciais.
- Utilize variáveis de ambiente.
- Escreva testes para as funcionalidades.
- Valide as respostas produzidas pela IA.
- Não execute ações arbitrárias sugeridas pela IA.

## Processo de desenvolvimento

- Trabalhe uma etapa por vez.
- Inspecione o projeto antes de modificá-lo.
- Execute os testes após cada etapa.
- Informe os arquivos modificados.
- Informe os comandos executados e resultados.
- Não avance silenciosamente com testes falhando.
- Peça confirmação para mudanças de arquitetura
  ou ações externas.

## Entrega

O resultado deve conter código funcional,
testes, README, .env.example e documentação
visual do fluxo n8n.
